# Spencer's Arcade

The game index at https://spencerrichardhenry.github.io/.

This is a static, responsive page. Edit `index.html` and `assets/arcade.css`,
then push `main` to publish with GitHub Pages. The preview images are screenshots
of the games. Barlow is bundled under its included SIL Open Font License.

- Tiny Tide: https://spencerrichardhenry.github.io/wildtag/tiny-tide.html
- Royal Yeet: https://spencerrichardhenry.github.io/wildtag/royal-yeet.html
- Dungeon Run (mobademo): https://spencerrichardhenry.github.io/mobatest/
- Wildtag: https://spencerrichardhenry.github.io/wildtag/
- Moss & Maw: https://spencerrichardhenry.github.io/moss-and-maw/
- Spin Arena: https://spencerrichardhenry.github.io/spin-arena/

The former `/garbage-dragon/` address redirects to `/moss-and-maw/`.
