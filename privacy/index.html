What gets recorded

When you start playing, the game creates a random session identifier and sends small playtime updates to a Cloudflare service. The records contain the game name, session identifier, timestamps, active play duration, and the IP address that connects to the service.

There are no analytics cookies, advertising profiles, screen recordings, or recordings of your keys, messages, or game saves. A temporary session record in browser session storage lets reloads and short breaks continue the same session.

How playtime works

Time counts while the game is in play, visible, and focused. Pauses, background tabs, and two minutes without input stop the clock. Holding a movement key or touch control counts as input. A break of more than 30 minutes starts a new session. Reports use Mountain Time.

Network interruptions, browser restrictions, and blocked analytics can cause some activity to go unrecorded. An IP address identifies a network connection: several people can share it, and one person’s address can change.

Who can see it, and for how long

The analytics dashboard is private to Spencer. Cloudflare hosts the collection service and database. Raw IP and session records have a 30-day retention period, with automatic cleanup each day. Daily totals by game remain after those detailed records are removed.

This page’s switch stops future analytics collection in this browser; it does not delete records already received. Global Privacy Control and Do Not Track signals also disable collection.

Questions or a data request?

You can contact Spencer through his GitHub profile. The dashboard reports network activity, so an IP address alone cannot prove which person played.
